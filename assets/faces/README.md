# Streamer reaction photos

The renderer selects one of the named close-up reactions for each editorial
hook: `shocked` for high-stakes surprises, `hold-on` for skepticism or a joke,
`hyped` for builds, and `smiling` for a payoff. PNG, JPG, and WebP work;
transparent PNG cutouts produce the best white-rimmed foreground silhouette.
Without the needed expression, the review render shows a labeled silhouette.

Re-run `uv run milloclips thumbnails
workspace/f1ca1ecfc69f` to composite photos without regenerating backgrounds.
